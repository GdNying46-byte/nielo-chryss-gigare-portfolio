# Nielo Chryss Gigare Portfolio

A simple, modern portfolio website for Nielo Chryss Gigare.

## Features
- Responsive hero section
- About section
- Featured project cards
- Skills grid
- Contact section
- Clean, elegant styling

## Run locally
Open `index.html` in a browser, or serve it with a small local HTTP server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files
- `index.html` — page structure
- `styles.css` — styling and responsiveness
- `script.js` — mobile menu toggle and footer year

## Customize
Update the text, email, and social links in `index.html` to match your real profile.
